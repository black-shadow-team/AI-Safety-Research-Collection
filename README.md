# AI-Safety-Research-Collection

A consolidated collection of research articles on LLM safety, defensive AI security, adversarial attacks, guardrail hardening, and modular AI system design by **Black Shadow Team**.

## Research Areas

- AI safety and LLM security
- Prompt injection mitigation
- Jailbreak and guardrail erosion prevention
- Role-play and persona sanitization
- Administrative impersonation protection
- Multimodal security
- Chain-of-thought validation
- Session memory management
- Ethical and responsible disclosure
